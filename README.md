
# LCD Stock Manager - Android App

He app hi Mobile Repairing Shop tan LCD stock enkawlna tur a ni.

## APK siam dan:

1. Android Studio hawng la
2. File > Open > he folder hi thlang rawh (LCDStockManagerApp)
3. Gradle sync nghak rawh (a hmasa ber ah internet a ngai)
4. Top ah Run button (▶) hmet la, emulator emaw i phone ah emaw a run ang
5. APK siam duh chuan: Build > Build Bundle(s) / APK(s) > Build APK(s)
   APK file chu app/build/outputs/apk/debug/ ah a awm ang.

## Features:
- Search rang tak (Awm / Awm lo a lang nghal)
- Stock + / - awlsam
- Brand, Model, Qty, Rack, Price
- Offline a hman theih, data bo lo

Mizo tawng support a awm.
