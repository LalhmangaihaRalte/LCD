
# LCD Stock Manager - GitHub ah dah dan

He repo hi mobile repairing shop LCD stock enkawlna tur a ni.

## GitHub ah dah dan (Minute 2 chhung):

### STEP 1: GitHub Repo siam
1. https://github.com ah lut la, Login rawh
2. Chunglam dinglam ah **+ > New repository** hmet rawh
3. Repository name ah: `lcd-stock-manager` ti rawh
4. **Public** thlang la, **Create repository** hmet rawh

### STEP 2: File upload
1. I repo thar ah chuan **"uploading an existing file"** tih link a awm ang, hmet rawh
2. He folder chhunga file zawng zawng hi drag & drop rawh (app folder leh .github folder zawng zawng)
3. A hnuai ah **Commit changes** hmet rawh

### STEP 3: APK Download nghal!
1. I repo ah chuan chunglam ah **Actions** tih tab hmet rawh
2. A veilam ah **Build APK** tih i hmu ang, click rawh
3. A dinglam ah **Run workflow** tih a awm chuan hmet la, a awm loh chuan push i tih tawh avangin a lo in-build mek a ni
4. Minute 2-3 nghak rawh, a zawh chuan **Artifacts** ah **LCD-Stock-Manager-APK** tih a lo awm ang
5. Chu chu download la, i phone ah install rawh!

APK direct link chu: Actions > latest run > Artifacts atangin download theih.
